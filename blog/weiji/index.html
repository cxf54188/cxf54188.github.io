🔒 姓名加密与显示

姓名以 AES-256 加密后写在页面里，页面源码中不含明文姓名，也不含任何答案。答对随机抽出的 3 道班级题，答案拼起来才是解密密钥 —— 答对才显示姓名。
验证通过前，榜单里的名字统一显示为「同学01…同学52」占位；验证通过后固定以标准脱敏形式（姓氏 + 缩写）显示。

标准脱敏姓名显示方式（固定）
· GitHub Pages 是纯静态托管，没有服务端，因此验证只能在浏览器里做；这层加密用于防止随手翻阅与源码搜姓名，不是绝对防护。拿到页面的人若懂得调试，理论上仍有办法绕过。
· 题库共 6 题、每次随机抽 3 题，共 20 种组合，每种组合单独加密一份，所以不存在"记住一组答案就能解开全部"的万能密钥。
· 「记住本机」会把姓名存在这台电脑的浏览器里；公共电脑请不要勾选。
· 答错时会先尝试自动关闭页面；浏览器通常不允许脚本关闭用户打开的标签页，此时会用全屏遮罩挡住全部内容，点「重新答题」换一批题重来。

📊 访问计数

页面访问次数由第三方计数器图片统计，图片会显示累计访问量。计数器位于页面顶部标题栏下方。
· 计数器由 count.getloli.com 提供，是一张外部图片，需要联网才会显示；断网或用 file:// 本地打开时可能不显示数字，不影响页面其它功能。
· 该服务只记录访问次数这一个数字，页面本身不会收集或上传任何浏览信息。
